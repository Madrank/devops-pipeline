Pipeline CI/CD

✅ Lint

Vérification de la qualité du code avec flake8

🧪 Test

Tests unitaires pytest avec rapport de couverture

🐳 Build

Image Docker multi-stage, push sur GitHub Container Registry

🚀 Deploy

Provisionnement EC2 avec Terraform, déploiement automatique

Stack technique

Application  → Python / Flask
Conteneur    → Docker / Docker Compose
CI/CD        → GitHub Actions
IaC          → Terraform (AWS)
Monitoring   → Prometheus + Grafana
Logs         → AWS CloudWatch

Démarrage rapide

make install      # Installer les dépendances
make test         # Lancer les tests
make docker-up    # Stack complet (app + Prometheus + Grafana)
